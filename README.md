# 게임 총기 개조 시뮬레이터 (Delta Force Gunsmith)

게임 Delta Force의 총기 개조 화면을 웹에서 그대로 해 볼 수 있는 시뮬레이터입니다.
부착물을 바꿔 끼우면 능력치 변화와 총 가격을 바로 계산해 보여 줍니다.

- 운영 주소: https://2ez4me.win
- 중국 서버 / 글로벌 서버 수치를 각각 제공, 한국어·영어·중국어 지원

## 동작 구조

```
[자동 수집] → [DB 적재·가공] → [화면용 데이터 생성] → [자동 배포] → [웹 화면]
 1시간마다      MySQL            JSON, 무기별 페이지    Cloudflare Pages   능력치·가격 계산
```

1. Windows 작업 스케줄러가 1시간마다 `collect.ps1`을 실행합니다.
2. 공개 데이터를 내려받아 MySQL에 원본 그대로 저장하고, 저장 프로시저로 무기·부품·슬롯·능력치·가격 테이블에 정리합니다.
3. 정리된 데이터를 웹 화면용 JSON과 무기별 페이지로 만듭니다.
4. 바뀐 파일만 Cloudflare Pages에 올립니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `collect.ps1` | 수집 → 적재 → 생성 → 배포 전체를 실행하는 스크립트 |
| `schema.sql` | 테이블 26개와 뷰 |
| `procedures.sql` | 원본을 테이블로 옮기는 저장 프로시저 8개 |
| `*_seed.sql` | 한국어·영어 이름 등 기초 데이터 |
| `web/` | 웹 화면 (`index.html`, `app.js`, `style.css`), 프레임워크 없이 작성 |
| `web/data/` | 화면이 읽는 JSON (자동 생성) |
| `tools/` | 이미지 WebP 변환, 무기별 페이지 생성 (Node.js) |
| `serve.ps1` | 내 PC에서 미리 보기 |

## 주요 구현

- **서버별 패치 반영**: 중국 서버에 먼저 패치되고 글로벌 서버는 며칠 뒤 적용됩니다. Steam 클라이언트 빌드 변경과 공식 공지를 함께 확인해 글로벌 수치를 자동으로 전환합니다.
- **출처 간 수치 병합**: 패치 전 공식 수치를 기준값으로 저장해 두고, 패치 후 기준값에서 달라진 쪽을 채택합니다.
- **슬롯 배치**: 총 이미지의 윤곽을 읽어 총구·탄창·손잡이 위치를 찾고, 슬롯 상자와 연결선이 겹치지 않게 배치합니다.
- **속도**: 이미지를 WebP로 변환하고, 파일 내용으로 버전을 붙여 캐시를 갱신합니다.

## 사용 기술

PowerShell, MySQL 8, JavaScript, HTML/CSS, Node.js, Cloudflare Pages, Windows 작업 스케줄러

## 실행에 필요한 것 (저장소에 없음)

- `mysql.cnf`: DB 접속 정보
- `cloudflare.txt`: 배포용 토큰
- `web/img/`: 게임 이미지 (수집할 때 자동으로 내려받음)

## 데이터 출처

- 무기·부착물 이름, 이미지, 기본 능력치, 중국 서버 가격: Tencent 공개 데이터
- 부착물 능력치와 장착 규칙: DFTTK
- 글로벌 서버 가격: deltaforcetools.gg

기능은 직접 기획하고 AI 코딩 도구를 활용해 구현했습니다.
